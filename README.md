# Riviera Prep Rebounding Report

Client view of Riviera Prep's 2025-26 varsity boys basketball rebounding: record, headline numbers, charts and splits.

**View the report:** https://eng5000.github.io/HSBBData2/

`index.html` is self-contained (logo, colors, data and chart code are all inside), so it also opens offline by double-clicking.

- **Logo:** the `CLIENT LOGO` line near the top of `<body>`. Paste a new `data:image/...` URL into `src=""`, or set `src=""` to hide it.
- **Colors:** the `CLIENT COLORS` block at the top of `<style>`.
- **Paint touches:** the `PAINT` list in the script holds **sample** numbers for practice, not tracked data.
